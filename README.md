# Abhinav Kumar Singh | Portfolio

A responsive Cloud Data Engineer portfolio based on the supplied visual reference.

## Files
- `index.html` — page structure and content
- `styles.css` — styling, responsive layouts, animations, and themes
- `script.js` — interactions and motion
- `Abhinav_Kumar_Singh_Resume.pdf` — resume download (keep beside `index.html`)

## Run locally
Open `index.html` in a browser, or use VS Code Live Server. The Google Fonts import needs an internet connection; system font fallbacks are included.

## Included interactions
- Loading intro and scroll progress indicator
- Light/dark theme toggle
- Mobile navigation
- Animated cursor-aware avatar and background data flow
- Bronze/Silver/Gold Medallion tabs
- Front-end pipeline simulation
- Experience filters and SQL-style skills filters
- Copy-to-clipboard contact controls

The pipeline animation is a portfolio demonstration only. It does not execute a real data pipeline.
